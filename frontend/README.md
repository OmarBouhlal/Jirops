# Jirops Frontend

React + Tailwind dashboard for the Jirops backend.

## Run locally

1. Start the backend gateway on `http://localhost:8080`.
2. Install dependencies in this folder.
3. Run `npm run dev`.

## API target

The app uses the gateway by default through Vite's proxy in development.
Set `VITE_API_BASE_URL` if you want to point it somewhere else.
